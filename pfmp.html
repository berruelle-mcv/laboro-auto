Mode d'emploi :
  1. Cliquez sur un élève dans la liste (à gauche).
  2. Recopiez l'entreprise et le tuteur depuis la convention ou Pronote, puis choisissez le secteur : la grille s'adapte toute seule. Ajustez les exemples si besoin.
  3. Enregistrez, puis passez à l'onglet « Documents à imprimer ».

Élèves de la classe

Pour créer une classe en une fois : un élève par ligne, au format NOM Prénom (ou NOM ; Prénom, copié depuis un tableur). Les élèves déjà présents dans la liste sont ignorés : pas de doublon possible.

Sélectionnez un élève dans la liste ou ajoutez-en un.

Export groupé (PDF ou impression)

Cochez les élèves et les documents, puis cliquez sur le bouton. Dans la fenêtre qui s'ouvre, choisissez « Enregistrer au format PDF » comme destination pour l'enregistrer sur une clé USB, ou une imprimante.

Aperçu d'un élève

Mode d'emploi :
  1. Saisissez une fois la liste des professeurs de la classe (à gauche).
  2. Une fois la répartition faite, choisissez pour chaque élève le professeur qui fera la visite : son nom apparaît automatiquement dans le livret.
  3. Imprimez les fiches de visite : une page par professeur, avec ses élèves, les adresses et les tuteurs.

Sauvegarde

Les données sont enregistrées sur le serveur LABORO. Vous pouvez en garder une copie sur votre ordinateur, ou importer une sauvegarde (les fiches présentes dans le fichier sont ajoutées ou mises à jour, rien n'est effacé).
